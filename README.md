# Saad's portfolio

A responsive, beginner-honest cybersecurity portfolio. Built for GitHub Pages with one HTML file containing all CSS and JavaScript, and three local images. No frameworks, package install, external fonts, tracking, or build step.

## Files

- `index.html`: the complete site, styles, and behavior.
- `assets/saad-dark.jpg`: hero and gallery portrait.
- `assets/saad-formal.jpg`: gallery portrait.
- `assets/saad-golden.jpg`: About and gallery portrait.
- `.nojekyll`: tells GitHub Pages to serve the static files directly.

## GitHub Pages

In repository **Settings → Pages**, choose **Deploy from a branch**, then **main** and **/ (root)**, and save. GitHub Pages for a private personal repository requires an eligible paid GitHub plan. If using GitHub Free, the repository must be public to use Pages.

Expected address after Pages is enabled and its deployment succeeds:

Replace photo files at the same paths to update images; update their alt descriptions as well. Find `ztrace054@gmail.com` to change the contact email, including the copy-button value in the script.

The intro is decorative and skippable. Returning visits show the entry button immediately. The motion button and system reduced-motion preference disable animations. Main content remains accessible when JavaScript is disabled. The gallery supports keyboard navigation and Escape.

Open `index.html` directly for a local preview. Use GitHub Pages over HTTPS for the modern Clipboard API; a local-file copy fallback is also provided.
